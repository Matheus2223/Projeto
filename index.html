Sobre os dados deste protótipo

Transparência sobre o que é real e o que é simulado

Todos os números de produtos, vendas e engajamento exibidos neste site são dados de demonstração, criados para mostrar como a ferramenta funciona e como as análises seriam apresentadas.

Para transformar isso em uma ferramenta com dados reais, o caminho recomendado é:

  1. Vendas da sua própria loja: integrar a TikTok Shop Partner/Seller API (dados oficiais de pedidos, estoque e produtos da sua conta de vendedor).
  2. Tendências de mercado: usar o TikTok Creative Center (público, mostra anúncios e criativos em alta) combinado com ferramentas de terceiros especializadas em TikTok Shop, como Kalodata, EchoTik ou FastMoss, que já vendem acesso a rankings de produtos e vídeos por nicho.
  3. Análise de vídeos por perfil: essas mesmas ferramentas (ou a API oficial do TikTok for Business) fornecem métricas de visualizações, curtidas, comentários e compartilhamentos por vídeo e por conta.

Este site já está estruturado para receber esses dados: o arquivo js/data.js documenta o formato exato esperado para produtos, formatos de vídeo e perfis de criador — basta trocar os dados fixos por chamadas a uma API real seguindo o mesmo formato.

Importante: fazer scraping (raspagem automatizada) direto do TikTok viola os Termos de Serviço da plataforma e não é recomendado. Prefira sempre APIs oficiais ou parceiros autorizados.
